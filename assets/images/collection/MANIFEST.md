# Nature's Rhythm — image manifest

Which original shoot frame each file came from. The originals live in
`FINAL IMAGES FOR RR/` and are deliberately not tracked in this repository
(43-megapixel masters), so this table is the only record of the mapping.

Every file is cropped to 4:5 to match the listing container exactly and
exported at 1600×2000, progressive JPEG q82. The crop window is positioned
on the subject rather than the centre of the frame.

`-01` is the image used on the Nature's Rhythm tile on the home page.
